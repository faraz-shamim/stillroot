How the models work together

Forecast, then explain

TabPFN estimates the next moisture reading from past conditions. A small action policy turns uncertainty and time away into a care cue. Gemma explains that cue locally; it does not choose a watering amount.

Honest about the demo

This dataset is generated for a reproducible engineering test. It is not Rohan’s real plant history. Recorded TabPFN predictions power the three sample plants. An uploaded CSV uses a labeled portable baseline unless you run the local TabPFN service.

Care you can inspect

The care signal is a small, readable policy. Old readings require verification, wet soil never prompts a watering request, and a dry travel forecast suggests a friend check the soil. Gemma explains the result; it cannot change the policy.
